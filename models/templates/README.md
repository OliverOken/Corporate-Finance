# Corporate-Finance
Vemba 33 Finance 

Purpose
Contains financial modeling templates and populated models for the BUS-629 Corporate Finance project.

Structure
templates/: Canonical modeling templates provided by instructor
builds/: Populated models with actual company data (created at Stage 3)

Key Files
templates/performance-ratios-template.xlsx: Master template with pre-built formulas using named-range notation. Do not modify - serves as foundation for all subsequent stages.

Conventions
Templates remain unmodified to ensure consistency across all students
Populated models inherit the template's architecture and named-range structure
All ratio calculations are formulaic - no hardcoded values
Follow the template's color-coding: yellow (inputs), blue (assumptions), green (formulas), gray (outputs)

Usage
Stage 1: Upload template as-is
Stage 3: Create company-specific model in builds/ using template structure
Stage 4+: Reference named ranges when specifying analytical work for LLMs
